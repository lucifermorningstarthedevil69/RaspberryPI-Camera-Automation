Instructions for using Automated Terminal (Damage to Conductor) Test Apparatus

Automated Terminal Test Apparatus using Raspberry Pi with camera module and IR reflective sensor for testing household switches IS 3854 and plugs & socket outlets IS 1293.
1 Power and Initialization

Power on the 18w DC Adapter. Wait for 1-2 minutes for the system to boot and initialize the sensors.

2 Network Connection

Check the IP address on the screen and type the address with port 8080 in your browser.

http://[Device_IP_ADDRESS]:8080
Example: http://192.168.2.175:8080
3 Starting the Test

On the homepage, enter the Sample code and IS code. Set the timer and click "Start Test".

4 Automated Monitoring

If the weight drops, the system records a Test Failure automatically.

5 Reviewing History

View test result logs and download recording videos in the Test History Page.

The Test History tab shows a complete list of all test statuses (Pass/Fail), providing a clear overview of your test history.
Click the 'View' button to start instant video playback of the recorded test session for detailed analysis.
Easily Download videos or Generate Reports from logs. An option to Delete records is also available.
6 System Management

Monitor CPU, Memory, and Storage usage in the System Info Page.

Note: Always perform a proper system shutdown before removing power.
